# پایان‌نامه کارشناسی — سامانه سنجش شناختی (ctlg)

**عنوان پیشنهادی:** طراحی و پیاده‌سازی سامانه ارزیابی شناختی و یادگیری تطبیقی با تحلیل رفتار کاربر، ارزیابی کیفیت نرم‌افزار و بررسی پیش‌بینی ترک سامانه

**منبع حقیقت:** کد مخزن `ctlg-2` + README + نتایج تست/ML تأییدشده  
**زبان:** فارسی دانشگاهی  
**نسخه:** کامل (فازهای ۲ تا ۷ طبق `pro.txt`)  
**نکته بصری:** به‌جای اسکرین‌شات، **کد Mermaid** قرار داده شده است.

> **هشدار علمی:** فایل مقاله پژوهشی تیم در مخزن یافت نشد. بخش‌های مرتبط با مقاله بر اساس `README.md` و تطبیق با پیاده‌سازی نوشته شده و با برچسب «بر اساس README / نیاز به تکمیل با متن مقاله» مشخص شده‌اند.
